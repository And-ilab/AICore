## 3. Архитектурная схема

### 3.1. Функциональная архитектура

```text
[Портал / AI Hub UI]
        │
        ▼
[Django backend · ASGI/WSGI · RBAC]
   ├── модуль Контакт-центра (суфлёр тел./чат, онлайн-чат, QU, отчётность)
   ├── модуль ИИ-ассистент
   ├── модуль OCR
   ├── модуль LLM (ModelRegistry / gateway)
   └── audit → KUMA/file
        │
        ├── PostgreSQL + pgvector (индекс cc_production и пр.)
        ├── Redis (Celery broker/result)
        ├── MinIO (объекты / вложения)
        └── Celery worker
        │
[Внешние системы банка: СУЗ · Oktell · AD/LDAPS · SIEM]
```

### 3.2. Сетевая архитектура и информационные потоки

Ориентир локального/TEST-стека ([`backend/README.md`](../../backend/README.md), `infra/docker-compose.yml`):

| Компонент | Назначение | Host-порт (dev) | Протокол |
|-----------|------------|-----------------|----------|
| Backend (Django) | API, UI static, admin | 8000 | HTTP/HTTPS, WS |
| PostgreSQL + pgvector | СУБД, векторный индекс | 5432 | TCP |
| Redis | брокер/результаты Celery | 6379 | TCP |
| MinIO API | объектное хранилище | 9000 | HTTP |
| MinIO Console | админ UI MinIO | 9001 | HTTP |
| Frontend (Vite, опц.) | SPA оператора | 5173 | HTTP |
| ASR (отдельный сервис) | распознавание речи | 8765 (WS) | WebSocket |

| Поток | Источник → приёмник | Протокол / порт | Примечание |

## 4. Размещение компонент и конфигурация ПО

### 4.1. Рекомендуемое размещение (из backend README)

| Слой | Артефакт репозитория | Контейнер / процесс |
|------|----------------------|---------------------|
| Приложение | `backend/` | `backend` (migrate + runserver/ASGI) |
| Фоновые задачи | `backend/` + Celery | `celery-worker` |
| СУБД | `infra/postgres/` | `postgres` |
| Кэш/очередь | — | `redis` |
| Объекты | — | `minio` |
| UI | `frontend/` | Vite/nginx (_TBD prod reverse-proxy_) |
| Инфра | `infra/docker-compose.yml`, `infra/.env` | Compose project |

Запуск стека (сводка из [`backend/README.md`](../../backend/README.md)):

```powershell
cd infra
Copy-Item .env.example .env   # задать DJANGO_SECRET_KEY, POSTGRES_PASSWORD, MINIO_ROOT_PASSWORD
docker compose up --build -d
```

Основные URL после старта: приложение `http://localhost:8000/`, health `http://localhost:8000/health/`, Django admin `http://localhost:8000/admin/`, MinIO Console `http://localhost:9001/`.

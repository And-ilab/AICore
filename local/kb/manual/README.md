# Документы для локальной БЗ

Положите сюда файлы (до ~10 штук) для загрузки в «Базы знаний».

Поддерживаемые форматы: `.txt`, `.doc`, `.docx`, `.pdf`, `.rtf`, …

Загрузка в платформу (backend должен быть запущен):

```bash
py -3 tools/seed_manual_kb.py --base-url http://127.0.0.1:8000
```

В Admin center: **Базы знаний** → БЗ «Тестовые статьи (manual)» (источник: Ручная загрузка).
